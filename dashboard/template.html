The model is a ridge regression per position. It uses recent scoring, carries, targets and target share, Vegas implied team points, home/away, injury report status, and how many points the opposing defense has been allowing. Kickers and defenses are barely predictable week to week. Treat them as streaming picks. The test only includes players who actually played, so surprise inactives are not priced in.
